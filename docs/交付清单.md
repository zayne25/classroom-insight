## 三、运行环境与安装步骤

### 3.1 环境要求

| 组件 | 版本 | 是否必需 |
|---|---|---|
| JDK | 17+ | 必需 |
| MySQL | 8.0.16+（CHECK 约束需此版本） | 必需 |
| Maven | 3.8+ | 必需（或直接用仓库内 `runtime/` 便携版） |
| Docker | 20+ | 可选（用 `docker compose up -d` 免装 JDK/MySQL） |

### 3.2 三步跑起来（Windows）

```powershell
# 1) 建库建表建视图
mysql -uroot -p < db\schema.sql

# 2) 改数据库密码（若与本机不同）
#    编辑 src\main\resources\application.yml 的 spring.datasource.password

# 3) 启动（首次启动会自动生成演示数据，约 10~20 秒）
run.bat
# 浏览器打开 http://127.0.0.1:8080   账号 admin / 123456
```

### 3.3 Docker 方式（更省事）

```bash
docker compose up -d --build
# 访问 http://服务器IP:8080   admin / 123456
```

容器会**自动**执行 `db/schema.sql` 建库建表；应用启动发现 `users` 为空会自动生成演示数据，
所以不需要手动导数据。数据库数据存在 `mysql-data` 卷里，`docker compose down` 不会丢。

## 五、常见追问与答法（答辩备用）

| 追问 | 回答要点 |
|---|---|
| 数据是你编的吗？有没有分析价值？ | 演示数据引入"隐藏的学习能力潜变量"，高/中/低三档学生与出勤、互动、成绩存在相关性，所以图表才有可解释的结论（见 README 第八章） |
| 统计逻辑放在哪？ | 聚合全部下沉到 MySQL（7 个统计视图 + `AnalyticsMapper`），Java 层只做展示，避免把 3 万行数据拉进内存算 |
| 权限怎么控制？ | 三层：登录拦截器 → 角色粗筛（admin/teacher/student）→ 权限点细筛（24 个权限点，`requirePerm()`），再叠数据归属校验（教师只能操作自己的课） |
| 管理员改权限真生效吗？ | 是。教师端课堂/互动/作业/AI 批改写操作都调 `requirePerm()`，改完权限下一次请求即 403 |
| 配置是真配置还是摆设？ | 真用。密码策略参与注册/重置校验，预警阈值参与风险分级，登录失败锁定由配置驱动，系统名称实时改顶栏 |
| 备份怎么实现？ | 优先 `mysqldump`，失败自动降级为 JDBC 逻辑转储（`SHOW CREATE TABLE` + 批量 INSERT）；恢复前强制自动备份，防误操作 |
| 并发/一致性怎么保证？ | 签到与互动记录有唯一约束防重复；写操作在事务内完成；统计走只读视图 |
| 安全做了什么？ | BCrypt 存密码、绝不回传哈希；登录失败计数锁定；管理接口双重校验；危险操作二次确认 |
| 为什么不用 Spring Security？ | 本项目权限模型是"角色×权限点"动态配置，用拦截器 + 自定义权限服务实现更轻量、更容易讲清；Spring Security 的表达式鉴权对动态权限点反而更绕 |
| 系统边界/不足？ | 单机单体部署、无分布式缓存、AI 批改默认走离线启发式引擎（接真实大模型只需改配置）；备份文件不做异地存储 |

## 七、已知限制（主动说明，避免被当成 bug）

1. **AI 批改默认离线引擎**：`ai.grading.provider=local` 用启发式规则（关键词覆盖 + 长度 + 结构），用于演示完整流程；改成 `http` 并填 endpoint/api-key 即接真实大模型，失败会自动降级回 local。
2. **免费云平台限制**：Render/Railway 免费档会休眠、容器重启后备份文件丢失，仅适合演示。
3. **单机部署**：会话存内存，不支持多实例横向扩展（要做需引入 Redis + 分布式 session）。
4. **数据规模**：演示数据约 3.9 万行，针对教学演示量级优化；更大规模需要加分页索引与缓存。
