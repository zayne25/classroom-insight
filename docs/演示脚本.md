# 10 分钟演示脚本（答辩 / 验收用）

> 准备：本机 `run.bat` 已启动，浏览器开 3 个标签页（教师、学生、管理员），手机连同一 WiFi 也打开一个学生页。
> 账号：教师 `t001 / 123456`、学生 `20230101 / 123456`、管理员 `admin / 123456`（登录页有快捷按钮可直接点）。

---

## 开场（30 秒，一句话说清系统是什么）

> "这是一个大学课堂互动与学情分析系统：老师上课时用签到、抢答、投票、作业收集课堂数据，
> 系统把这些数据自动算成学情画像和预警名单，帮老师发现'该关注哪个学生'。"

技术栈一句话带过：**Spring Boot 3 + MySQL 8 + MyBatis + Thymeleaf，前后端同源，无额外前端构建**。

---

## 第一段：教师端（4 分钟）

### 1. 开课 + 签到码（40 秒）
1. 教师页 → 课程「数据库系统原理」→ **开始上课**
2. 屏幕上出现 **4 位签到码**（例如 3-7-2-9）
3. 说："签到码即时生成，学生端输入即可；迟到与否由课时开始时间自动判定，不用老师手动标。"

### 2. 实时互动（60 秒）
1. 点 **发布抢答**（或投票）→ 学生在手机上点答案
2. 教师看板 3 秒自动刷新，出现"谁先答、答了什么、正确率多少"
3. 说："互动看板是轮询 + 增量统计，不刷新整页；一次课结束所有响应自动沉淀成数据。"

### 3. AI 批改（90 秒，全场最亮的一点）
1. 作业列表 → 选一份"待批改"的提交 → **AI 批改**
2. 展示：**分数 + 置信度 + 评语 + 命中关键词 + 是否需人工复核**
3. 说三句关键话：
   - "低置信度（<0.75）自动标记需复核，**AI 不替老师做最终决定**"
   - "引擎可切换：本地启发式引擎离线可用，配一下 endpoint 就能接大模型，失败自动降级"
   - "老师可以改分，改完的动作会写审计日志"

### 4. 学情分析 + 预警（90 秒）
1. 学情分析页从上往下讲 3 张：出勤趋势、知识点掌握度热力图、成绩分布
2. 说："这些图不是前端拼的假数据，是 `AnalyticsMapper` 里 7 个视图聚合出来的。"
3. 预警页：红/黄/绿三级名单 + 自动归因标签（"出勤低""作业迟交"）
4. 点开一个红名单学生 → **个人学情**，说："一眼看到问题在哪，不用老师翻表格。"

---

## 第二段：学生端（2 分钟，用手机演示更有说服力）

1. 手机打开地址 → `20230101 / 123456` 登录
2. 输入刚才的签到码 → 签到成功、显示状态
3. 点进老师刚发的抢答 → 提交 → 老师端看板立刻多一条
4. 交一次作业（选附件或文本）→ 学生端能看到"已提交 / 已批改"状态
5. 说："学生端是响应式布局，按钮大、步骤少，手机单手可完成整节课的操作。"

---

## 第三段：管理员端（3 分钟，体现"完整系统"而不是"半个 demo"）

按顺序点六个页面，每页一句话：

| 页面 | 演示动作 | 一句话 |
|---|---|---|
| 系统监控 | 指标卡 + 运行状态自检 | "登录、账号规模、数据库、JVM、磁盘、失败操作一次看全" |
| 用户与角色 | 新建一个学生 → 停用 → 删除 | "删除前会查业务引用，有数据的账号只能停用，防误删" |
| 权限配置 | 关掉教师"作业批改"权限 → 切回教师端刷新 | **"关掉后教师端立即 403，权限是真生效的"** |
| 系统配置 | 预警红线 60 → 80 → 回预警页 | **"改完名单立刻变，配置驱动业务，不是摆设"** |
| 操作日志 | 筛选"配置"模块 → 点详情 | "看到'60 → 80'的改前改后、操作人、IP、耗时" |
| 数据备份 | 立即备份 → 看大小/表数/耗时 | "支持恢复，且恢复前会强制自动备份一次" |

## 演示注意事项

- **提前 10 分钟启动**，跑一遍签到和 AI 批改，确认热数据存在；
- 手机与电脑**连同一 WiFi**；若现场网络不通，直接用电脑单机演示（页面都做了响应式，窄窗口即可模拟手机）；
- 千万别在演示时改数据库密码或删数据；
- 若被问到答不上来的点，回到两句话：**"数据怎么来"（真表真视图）**、**"权限怎么控"（角色 + 权限点 + 数据归属三层）**。
